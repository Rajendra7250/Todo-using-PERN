📝 Todo App — PERN Stack

A full-stack Todo list application built using the PERN stack:
PostgreSQL, Express.js, React, and Node.js.

Features
- Create, read, update, and delete todos (full CRUD)
- RESTful API built with Express and Node.js
- PostgreSQL database for persistent storage
- React frontend with functional components and hooks
- Bootstrap modals for editing todos

Tech Stack
- Frontend: React, Bootstrap
- Backend: Node.js, Express
- Database: PostgreSQL
- API Testing: (e.g. Postman, if you used it)

Getting Started
1. Clone the repo
2. Set up a PostgreSQL database and update your .env with connection details
3. Run `npm install` in both /client and /server directories
4. Start the backend: `npm start` (in /server)
5. Start the frontend: `npm start` (in /client)
